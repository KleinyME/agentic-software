# Writing Quality Standards — Prohibited Language and Replacement Strategies

Source: CPS V6.000 + 100 Year Copywriting Engine V13.001 + Ken's Voice Guide — Ad Zombies

Strong copy is specific, direct, and original. These patterns often make copy weak, forgettable, or untrustworthy. Flag the effect in context; an approved voice sample, quoted customer language, necessary legal phrasing, or deliberately subverted cliché may justify an exception.

---

## HIGH-RISK TRANSITIONAL CLICHÉS

Treat these as strong review candidates, especially when they announce a point instead of making it:

**Default removal candidates:**
- "Here's the kicker" / "Plot twist" / "Speaking of"
- "That being said" / "On that note" / "Let's break it down"
- "Here's the deal" / "Real talk" / "Picture this"
- "But wait, there's more" / "It gets better" / "Here's the thing"
- "Long story short" / "At the end of the day" / "Moving on..."
- "Anyway..." / "With that in mind" / "Having said that"
- "Now then" / "So yeah" / "The thing is"
- "What's more" / "Not only that" / "In other words"
- "Buckle up" / "Let's dive in" / "Let's unpack this"
- "Spoiler alert" / "Hot take" / "Truth bomb" / "Fun fact"
- "Pro tip" / "Quick tip" / "Insider tip" / "Bonus tip"

## TIRED COMPARISONS AND METAPHORS

Replace with original, specific alternatives:

**Usually replace:**
- "Faster than a..." / "Quicker than..." / "As popular as..."
- "Better than..." comparisons that use "___ than a ___" structure
- "Like a kid in a candy store"
- "Like watching paint dry"
- "Like a bull in a china shop"
- "As easy as pie"
- "As smooth as silk"
- "Thinking outside the box"
- "Low-hanging fruit"
- "Move the needle"
- Any overused business jargon

**In Ken's voice specifically, also avoid:**
- "Watching paint dry"
- "Thinking outside the box"
- "Low-hanging fruit"
- "Move the needle"

## REDUNDANT AND WEAK PHRASES

**Usually tighten:**
- "Each and every" → "Every"
- "First and foremost" → "First"
- "At this point in time" → "Now"
- "Due to the fact that" → "Because"
- "In order to" → "To"
- "The reason why" → "Why"
- "What I mean is" → (just say it directly)
- "Basically" → (remove entirely)
- "Essentially" → (remove entirely)
- "Actually" → (almost always removable)

## REPLACEMENT STRATEGIES

### Instead of Clichéd Transitions
- Use thematic links between ideas
- Create narrative flow through shared concepts
- Employ parallel structure for connection
- Bridge with relevant, original questions
- Build logical progression naturally

### Instead of Tired Comparisons
- Draw from current events and trends
- Use industry-specific references
- Create unexpected, original metaphors
- Make fresh connections between unrelated concepts
- Develop extended analogies that serve the message

### For Enhanced Emphasis
- State important points directly and powerfully
- Use strategic line breaks and white space
- Employ contrast for dramatic effect
- Create mini-cliffhangers that maintain interest
- Build anticipation through logical progression

## EM DASH FORMATTING STANDARD

**In all contexts EXCEPT Ken's voice:**
- **Correct:** word—word (no spaces)
- **Incorrect:** word - word (with spaces)

**In Ken's voice:**
- Avoid em dashes entirely unless the user explicitly requests them.

## QUALITY CHECKLIST (Pre-Publication)

### Content Review
- [ ] All prohibited phrases screened and removed
- [ ] Original metaphors (not clichés)
- [ ] Humor serves the message, not the writer
- [ ] Personality without reliance on tired formulas

### Technical Check
- [ ] Proper em dash formatting (or absent in Ken's voice)
- [ ] Consistent formatting across sections
- [ ] Appropriate paragraph length (short = scannable)
- [ ] Clear hierarchy in longer pieces

### Engagement Assessment
- [ ] Strong, original opening (would YOU keep reading?)
- [ ] Clear value proposition visible without scrolling
- [ ] Natural flow of ideas
- [ ] Memorable, purposeful closing

### Brand Alignment
- [ ] Maintains professional standards
- [ ] Serves target audience (not just the writer's ego)
- [ ] Achieves business objectives
- [ ] Social proof is real and verifiable

## OVERUSED OPENERS

These openers usually signal that the underlying idea needs more creative work. Preserve one only when the approved voice uses it deliberately and the line earns its place:
- "Buckle up"
- "Here's the deal"
- "Let's break it down"
- "Plot twist"
- "Real talk"
- "Are you ready to..."
- "In today's fast-paced world..."
- "Have you ever wondered..."
- "Did you know that..."
- "Once upon a time..."
- "We've all been there..."
