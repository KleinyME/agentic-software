# Principle Index

Principles are named steering handles. Say the name to redirect work in one phrase, and cite the name in a decision record instead of restating the rule. Other skills reference a principle by name; the rule text lives in exactly one card.

| principle | group | rule |
|---|---|---|
| [never-block-on-the-human](../principle-never-block-on-the-human/SKILL.md) | autonomy | Act on reversible work without asking; gate the irreversible at the boundary where consequences become real. |
| [prove-it-works](../principle-prove-it-works/SKILL.md) | verification | Verify against the real artifact, never a proxy, a self-report, or "it compiles". |
| [fix-root-causes](../principle-fix-root-causes/SKILL.md) | verification | Reproduce first, ask why until you reach the cause, and fix it at the source. |
| [subtract-before-you-add](../principle-subtract-before-you-add/SKILL.md) | design | Remove dead weight, redundant validators, and stubs first, then build on the simpler base. |
| [guard-the-context-window](../principle-guard-the-context-window/SKILL.md) | delegation | Route bulk to dispatched agents in fresh contexts; keep summaries in the main thread. |
| [encode-lessons-in-structure](../principle-encode-lessons-in-structure/SKILL.md) | meta | Encode a lesson as a type, lint, test, or script instead of more instruction text. |

Citing a principle means naming the specific decision it changed. A citation with no decision behind it means it was not applied.
