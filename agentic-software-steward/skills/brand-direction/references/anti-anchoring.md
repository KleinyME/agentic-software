# Anti-Anchoring Workflow

Use this workflow when an existing page, previous draft, or reference site might constrain reimagination.

## Separate Facts From Expression

Create a neutral evidence inventory before drafting:

- Business facts and history.
- Products and services.
- Real proof and source material.
- Required legal or operational boundaries.
- Existing working functionality.
- Audience facts.

Do not carry forward the old headline, section order, layout, tone, or visual hierarchy merely because it exists.

## Blank-Page Pass

1. Put the old expression aside after extracting facts.
2. State the new audience, desired perception, central promise, and primary action.
3. Create the message hierarchy and visual direction from those inputs.
4. Draft the new structure without consulting the old section order.
5. Only then compare with the existing site for missing facts or useful assets.
6. Produce a `keep`, `rewrite`, `remove`, and `introduce` map.

## Reference-Site Discipline

Analyze reference sites by qualities:

- Information density.
- Page rhythm.
- Typography and hierarchy.
- Photography or illustration treatment.
- Trust and proof presentation.
- Emotional register.
- Interaction model.

Never lift a competitor's copy, distinctive layout, photography, logos, or other protected expression. References provide a baseline and vocabulary; the user's differences and desired feeling have higher priority.

## Review Test

Before implementation, ask:

- Would this direction still exist if the old page disappeared?
- Does each section have a new job?
- Is anything preserved only because it was already present?
- Does the result express the requested difference, or merely reskin the baseline?
