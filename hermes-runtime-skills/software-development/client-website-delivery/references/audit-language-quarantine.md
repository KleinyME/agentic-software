# Audit Language Quarantine

Use this when a public-facing preview is being built from an audit, blueprint, or strategy artifact and visible copy starts sounding like commentary about the site instead of copy for the visitor.

## Core rule

Keep a hard boundary between:
1. **audit/report outputs** — evidence, gaps, priorities, proof plan, readiness, recommendations
2. **build/copy inputs** — approved facts, sector context, brand voice, proof, CTA constraints, forbidden claims
3. **rendered site copy** — language addressed directly to the visitor

## Use the audit for

- missing information
- missing trust/proof
- visitor questions
- content areas needing pages or sections
- SEO/AEO facts that must survive redesign
- claims needing verification before publishing

## Do not use the audit for

- paraphrasing findings into hero/subheads
- describing the page as clearer, easier, simpler, or warmer
- narrating site structure or navigation improvements
- generic strategist language about friction or clarity

## Review gate

Inspect hero copy, routing cards, section headings, CTA support text, FAQ intros, and final CTA bands. If it sounds like a strategist describing a better website rather than a real organization talking to a visitor, rewrite from visitor needs and source-backed facts.
